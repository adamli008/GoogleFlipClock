# Google Flip Clock for macOS (中文版)

这是一款专为 macOS 打造的高级机械样式翻页时钟应用，采用 SwiftUI 构建。让您在桌面即可体验经典的机械翻页美学。

## ✨ 功能特点

- **经典翻页时钟**：通过 3D 机械翻页动画精准显示当前时间。
- **动态动画效果**：基于弹簧物理系统的灵动动画，具有真实的过冲与回弹效果。
- **机械感设计**：数字卡片设计模拟真实的塑料材质，具有中间铰链和独立的正背面光效。
- **多种模式**：
    - **时钟模式**：显示当前时间、日期以及星期（中文显示）。
    - **计时器模式**：支持正向计时（秒表功能）。
    - **倒计时模式**：可自定义时长的倒计时器（默认 10 分钟），支持快速设置预设。
- **响应式布局**：在任何窗口尺寸下都能自动缩放并保持 16:9 的黄金比例。
- **菜单栏集成**：支持通过 macOS 菜单栏快速访问及切换模式。
- **高级美学**：针对深色模式优化，具有柔和渐变、细腻阴影和机械铰链细节。

## 🛠 技术详情

- **框架**：SwiftUI (支持 macOS 12.0+)
- **架构**：采用单文件整合优化方案，确保构建的极致稳定。
- **动画实现**：利用自定义 `rotation3DEffect` 结合物理属性和真实卡片剪裁逻辑。
- **状态管理**：使用 `ObservableObject` 和 `Combine` 实现实时同步。

## 🚀 快速上手

1. 在 **Xcode** 中打开项目。
2. 选择您的 Mac 运行目标。
3. 按下 **Cmd + R** 进行构建并运行。

## 💡 使用小贴士

- **切换模式**：使用底部的导航栏或菜单栏中的“切换模式”菜单。
- **重置计时/倒计时**：点击圆形的重置按钮，即可返回上一次设置的时长。
- **设置自定义倒计时**：在倒计时字段中输入分钟数并点击“Set”即可。
